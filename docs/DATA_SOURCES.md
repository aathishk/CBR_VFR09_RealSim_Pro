# Data Sources & Attribution

- GeoFS: public feature descriptions and official instructions were used as product-behavior references only. No GeoFS source code or proprietary assets are copied.
- God's Eye View: MIT-licensed architectural reference. Its repository separately documents third-party data licenses; this project uses the architectural ideas, not third-party bundled assets.
- Google Maps / Photorealistic 3D Tiles: optional, requires the user's own restricted API key and is subject to Google Maps Platform terms.
- Cesium ion: optional terrain / hosted 3D route, requires the user's own token and is subject to Cesium terms.
- OpenStreetMap / Overpass: building fallback data; ODbL attribution/share-alike requirements apply.
- OpenSky Network: optional live traffic; obey the provider's current license/usage terms.
- AviationWeather.gov: METAR weather proxy.
- Airports Authority of India eAIP: current VOCB runway and radio-navigation reference data used in the simulator; the simulator is not a substitute for operational charts.
